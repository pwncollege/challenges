Your calculator can turn text into numbers and numbers back into text.
Other programs need those operations too, along with ways to assemble messages and read input.
A standard library collects useful operations like these so programs can reuse them.

Here, you'll build your own versions of two familiar pieces of the C standard library: formatted output and formatted input.
You'll start with a `printf` program, then write functions that scan strings and read from standard input.
Keep building on your earlier solutions, and use your new input and output code to give your calculator an interactive interface.
