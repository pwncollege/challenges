An HTML injection can alter how the browser parses markup that follows it even when Content Security Policy blocks JavaScript.
Leaving an attribute value unfinished can make later page content part of a resource URL, causing the browser to send that content to another origin.
This technique is called dangling-markup injection.
Use the administrator's review page to capture its token without JavaScript, then redeem the token for the flag.
